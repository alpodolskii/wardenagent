# WardenAgent

Личный ИИ-агент, в котором безопасность заложена в архитектуру, а не добавлена сверху.

- **Любая модель.** Claude, OpenAI, OpenRouter или локальная. Меняется одной строкой в конфиге.
- **Зоны.** Личный помощник и health-ассистент живут в отдельных контейнерах, со своими данными и своей сетью.
- **Политика.** Агенту доступны только разрешённые инструменты, опасные действия требуют подтверждения владельца.
- **Секреты.** Ключи не попадают в контекст модели.
- **Сеть.** Наружу только по белому списку хостов.
- **Журнал.** Все действия записываются, подмена записей обнаруживается.
